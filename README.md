# Hasunosora Knowledge Base

莲之空文本知识库，项目标识为`hasunosora-knowledge-base`。

本项目围绕蓮ノ空女学院スクールアイドルクラブ整理公开百科资料，供查阅、检索增强生成（RAG）和个人知识库使用。内容涵盖企划、角色、声优、歌曲与唱片、演出、游戏、剧情配信及关联作品。项目由第三方整理，与企划官方及来源站点无隶属关系。

事实正文以日文为主，辅以中文分类、说明和部分概述。

## 资料范围

资料来自[日文维基百科](https://ja.wikipedia.org/wiki/ラブライブ!蓮ノ空女学院スクールアイドルクラブ)及[Link！Like！ラブライブ！Wiki](https://wikiwiki.jp/llll_wiki/)。当前整理范围涉及228个日文维基相关地址和链接啦Wiki目录中的1149个正文页面，重定向关系单独保留说明。收录范围可在[页面覆盖清单](说明与索引/页面覆盖清单.md)核对。

上传版本共有52篇Markdown分卷，包含21732个资料单元。日文维基部分保留开放许可正文，并整理表格与重复重定向；链接啦Wiki部分采用事实字段、机制说明、人物概述和关联题名索引。长篇评述、剧情简介及配信宣传的概述不保证保留原文每一项细节。图片、音视频、完整歌词、整段台词和评论区不在文本范围内。

页面覆盖记录用于说明指定范围内的读取结果，不能据此推定所有相关页面均无遗漏，也不能代替事实核查。具体处理方式见[完整性口径与例外](说明与索引/完整性口径与例外.md)。

## 分层目录

[核心必读](上传用Markdown/01_核心必读)集中企划沿革、学院与角色、成员关系、主要声优的基本资料和主线基础，适合建立通用莲之空知识库。

[直接相关](上传用Markdown/02_直接相关_作品演出与剧情)收录歌曲、唱片、演出、配信档案和跨媒体内容。[游戏专项](上传用Markdown/03_专项资料_游戏与历史数据)进一步保留卡牌、关卡、资源、规则与历史版本详表。

[声优与制作延伸](上传用Markdown/04_延伸阅读_声优与制作背景)涵盖声优职业活动、个人节目、历史所属团体、合作人物及制作单位背景。关注声优时，可与核心层一并使用。

[外围背景](上传用Markdown/05_外围背景_其他作品与系列)保存通过声优履历或系列关系关联的其他作品、角色、团体和发行物。层级表示通用问答的建议检索优先级，具体导入范围可按用途调整。

## 使用方式

从[上传用Markdown](上传用Markdown)选择所需层级内的.md文件，导入支持Markdown的知识库。完整文件目录见[资料目录](说明与索引/资料目录.md)。本文本库尚未生成向量索引，也不包含训练完成的模型。

[按来源核对](按来源核对)保存同批内容的原条目核对稿，主要用于人工检查。它与上传版本存在内容重合，导入时选择一套即可。[覆盖记录](覆盖记录)保留来源映射、资料单元和核验结果，供程序处理与追溯。声优及关联页面的扩展依据见[拓展清单](说明与索引/声优及关联页面拓展清单.md)。

资料中保留作品本身的日期与原页版本。使用时应区分角色与现实声优、不同期别、曲目版本和玩法条件，并沿用来源中的计划、未知及限定语境。社区观点与推测不应直接当作官方结论。
