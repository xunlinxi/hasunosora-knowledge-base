『 ばっどがーる 』（ 英 : BADGIRL ）は、 肉丸 による 日本 の 4コマ漫画 作品。『 まんがタイムきららキャラット 』（ 芳文社 ）にて、2021年2月号から4月号までゲスト掲載後 [ 1 ] [ 2 ] [ 3 ] 、同年5月号より連載中 [ 4 ] 。 ニコニコ静画 内の『きららベース』では本編の追っかけ連載に加えて番外編となるミニエピソードが掲載されている。

メディアミックスとして、 テレビアニメ が2025年7月から9月まで放送された [ 5 ] 。

## あらすじ

私立藤ヶ咲高校に通う主人公・ 優谷優 は、学園のマドンナで風紀委員長の 水鳥亜鳥 を神と崇(あが)め、路傍の石の良い子から彼女の目に留まる不良を志すことに。幼馴染の 涼風涼 に見守られ、時に亜鳥からの接近に過呼吸を起こしながら、優は不良を目指していく。

## 登場人物 ＞ 主要人物

優谷 優 （ ）

声 - 橘杏咲 [ 5 ]

誕生日：9月9日 / 身長：145.5cm / 体重：ひみつ

本作の主人公。私立藤ヶ咲高校1年。学園のマドンナで風紀委員長である亜鳥に憧れを超えた信仰心を持ち、彼女の目に留まるために不良を志している。 エクステ によるツートンヘアやピアス代わりのクリップなど、校則の範囲内で不良に寄せた外見をしているが、内面は成績優良かつ教職員からの評判も上々の優等生。反面、自転車すら乗れないほど運動神経は悪い。亜鳥から不意の接近を受けると「コヒュッ」という声と共に過呼吸を起こしてしまう。

水鳥 亜鳥 （ ）

声 - 花宮初奈 [ 5 ]

誕生日：8月8日 / 身長：164cm / 体重：48kg

藤ヶ咲高校3年。風紀委員長。風紀委員でありながら少しズレたところもあるが、才色兼備で周囲から敬愛される学園のマドンナ。優だけでなく校内外に「アトリスト」と呼ばれるファンを持つ。自分の人気を自覚しており、徹底的なまでにマイペースに振る舞う。優のことは可愛い子犬のような存在程度にしか認識していない。涼からは優を巡るライバルとして嫌われているが、亜鳥は涼の事を「(他人から)あんな嫌そうな顔をされるのは初めて」と新鮮な印象を受けて気に入っている。

涼風 涼 （ ）

声 - 松岡美里 [ 5 ]

誕生日：10月10日 / 身長：166cm / 体重：46kg

優の幼馴染。藤ヶ咲高校1年。生まれながらの金髪と目つきの悪さを備える「ナチュラル・ボーン・アウトロー」だか、冷静沈着な常識人でツッコミ役。不良を目指す優を見守っている。見た目がキツいので級友達からは恐れられているが、優しい本性を知った隠れファンも多い。亜鳥の事を嫌っているが、顔だけなら好みらしい。亜鳥を制裁出来る唯一の人物で、容赦なく殴る事もある。

瑠璃葉 るら （ ）

声 - 花井美春 [ 5 ]

誕生日：3月31日 / 身長：146cm / 体重：なし

藤ヶ咲高校2年。「るー」の愛称で呼ばれているが、優からは出会った時の紆余曲折から「しじみ先輩」とも呼ばれている。可愛らしい顔立ちと小柄ながらグラマラスな体型で美容系 Yチューバー や読者モデル、コスプレイヤーとしても活動している学園のアイドルだが、人見知りな面があり友人は少ない。自身の外見に絶大の自信を持っていたが、亜鳥を絶対視する優に打ち砕かれる。

清木 清 （ ）

声 - Lynn [ 6 ]

誕生日：11月11日 / 身長：161cm / 体重：44.5kg

亜鳥の友人。藤ヶ咲高校3年。図書委員長。亜鳥の事が好きだが、大の女好きで亜鳥以外の女子にも手を出しており、優の事も「つまみ食い」しようとした。亜鳥への思いはかなり捻(ひね)くれており、美しい存在だからこそ汚したいと考えるタイプ。作者曰く「一番やばい奴」。

水鳥 水花 （ ）

声 - 前田佳織里 [ 6 ]

誕生日：1月11日 / 身長：149.5cm / 体重：43kg

亜鳥の妹。藤ヶ咲高校1年で優や涼のクラスメイト。重度のシスコンで、姉への思いの強さは優に負けず劣らずで、優とは出会う度にライバルとして張り合っている。姉に執着し続けてきたせいで友人がおらず、動物と話せるようになった。日常は姉の観察ばかりで勉強を殆どしておらず、成績はかなり悪い。
