豊田 萌絵 （とよた もえ、 1995年 3月15日 [ 7 ] - ）は、 日本 の 女性 声優 。 茨城県 出身 [ 5 ] 。 響 所属 [ 5 ] 。

## 来歴

声優を目指したのは、元々マンガやアニメ、ゲームが好きな「ザ・オタク」であり、ステージでの歌唱やラジオ、舞台への出演などマルチに活動する声優の姿を見て「私のやりたいことが全部詰まっている！」と思ったことがきっかけ [ 8 ] 。その後、高校3年生の進路を考えるタイミングで、のちに所属することになる スタイルキューブ のオーディションに応募した [ 8 ] [ 9 ] 。

2012年、第1回スタイルキューブ声優オーディションを経て、研修生として同事務所に所属 [ 10 ] 。同年9月、『 この中に1人、妹がいる! 』の生徒役で声優デビュー [ 1 ] 。

2013年4月、同じ研修生の 伊藤美来 とともに声優ユニット「 StylipS 」への加入が発表された [ 11 ] [ 12 ] 。また、伊藤と同時に研修生から本所属に切り替わった [ 10 ] 。

2015年5月、伊藤美来とともに声優ユニット「 Pyxis 」を結成 [ 13 ] [ 7 ] 。

2017年7月26日、自身初となる写真集『moRe』を発売 [ 14 ] 。

2021年11月3日、短編映画『初恋がのった電車』で実写映画初主演をすることが発表された [ 15 ] 。

2022年10月31日より、デビュー10周年を記念し、オリジナルミニアルバムを制作する クラウドファンディング の募集が開始された [ 16 ] 。募集開始日にして支援目標金額を達成した [ 17 ] 。

2023年12月18日、集英社のデジタルコンテンツから選出される「 グラジャパ!アワード2023 」で週プレ プラス！賞を受賞 [ 18 ] [ 19 ] 。

2024年5月20日発売の『週刊プレイボーイ』23号で初となる表紙掲載 [ 20 ] [ 21 ] [ 22 ] 。

2025年12月31日をもってスタイルキューブを退所 [ 23 ] 、2026年1月1日より 響 に所属 [ 24 ] [ 25 ] 。

## グラビア活動

豊田は声優活動と並行して、写真集の刊行や雑誌グラビアへの出演を行っている。

2017年7月26日には、初の写真集『moRe』を主婦の友インフォスから刊行した。同作はグアムで撮影され、初公開の水着カットが収録された。豊田は後年のインタビューで、水着での撮影を新たな表現への挑戦として捉えていたと振り返っている。 [ 33 ] [ 34 ]

『moRe』では豊田自身がセルフプロデュースを手がけ、撮影地や衣装、シチュエーションなどを選定した。制作にあたっては、自身の個性を生かすとともに、女性読者にも楽しんでもらえる写真集にすることを意識したという。

また、撮影後には写真を印刷して並べ替えながらページ構成を検討し、写真の配置や視線のつながりにもこだわった。 [ 35 ]

2018年には、 伊藤美来 との声優ユニット・ Pyxis として『週刊ヤングジャンプ』のグラビアに登場した。

2019年7月1日には2冊目の写真集『moEmotion』を刊行。同作はトルコのイスタンブールやカッパドキアなどで撮影され、初めてランジェリー姿の撮影にも挑戦した。

2020年8月7日には、声優誌『声優グランプリ』の連載企画をまとめたフォトブック『もえしぐらし』を刊行した。 [ 36 ] [ 37 ] [ 38 ]

2022年1月31日発売の『週刊プレイボーイ』7号では、同誌のグラビアに初登場した。撮影は千葉県九十九里で行われ、休日の小旅行をテーマとしたグラビアが掲載された。

これに合わせてデジタル写真集『OFF-MODE』も配信され、同作品は集英社のグラビア配信サイト「グラジャパ！」の月間ランキングで9位となった。豊田は出演の経緯について、声優誌とは異なる読者層にも自身を知ってもらう機会になると考えたと説明している。 [ 39 ] [ 40 ]

2023年には『週刊プレイボーイ』の有料グラビアコンテンツ「週プレ プラス！」の企画「＋Special」に出演し、沖縄で撮影されたグラビアを公開した。

同年には、集英社のデジタルグラビアを対象とした「グラジャパ！AWARD 2023」で「週プレ プラス！賞」を受賞した。 [ 41 ] [ 42 ]

2024年5月20日発売の『週刊プレイボーイ』23号では、同誌で初めて表紙および巻頭グラビアを担当した。誌面に加え、撮影に密着した映像やインタビューを収録した付録DVDも制作された。

同月24日には、約5年ぶりとなる3冊目の写真集『moe』を集英社から刊行した。同作は20代最後の写真集として制作され、ニュージーランドのオークランドやロトルアなどで撮影が行われた。

豊田は2冊目の写真集を刊行した2019年から、20代の最後にもう一度写真集を制作することを目標としていたという。 [ 43 ] [ 44 ] [ 45 ]

『moe』の撮影地は豊田自身の希望によって選ばれた。写真の選定に際しては、従来の自身の表情に対するこだわりを見直し、編集者と相談しながら、それまでなら採用しなかった自然な表情の写真も収録した。

豊田は、年齢や仕事の経験を重ねたことで、飾らない自分の姿にも自信を持てるようになったと説明している。また、写真集の発売記念イベントでは、今回の作品を自身の写真集制作における一つの集大成と位置づけながらも、将来的に再び写真集を制作する可能性について言及した。 [ 46 ] [ 47 ]

同年には、声優の 石飛恵里花 の写真集『どのえりか？』にプロデューサーとして参加した。同作は11月15日に発売され、石飛と親交のある豊田も制作に関与した。写真集の被写体としての活動に加え、他の声優の写真集制作にも携わった。 [ 48 ]

2026年5月18日発売の『週刊プレイボーイ』22号では、約2年ぶりに同誌のグラビアに登場した。サウナやプール、テニス、グランピングなどを取り入れた撮影が行われ、関連するデジタル写真集『Day by Day』も発売された。

同年8月3日発売の同誌33号では再び表紙および巻頭グラビアを担当した。撮影はタイのパタヤとバンコクで行われ、デジタル写真集『また、好きになる。～prologue～』も配信された。 [ 49 ] [ 50 ] [ 51 ]

2026年10月のインタビューでは、写真集『moe』の制作後には達成感から一区切りついたと感じていたものの、その後も撮影の依頼を受ける中で再びグラビアに取り組みたいという気持ちが生まれたと語った。

また、30代になってからの撮影では、それまで行っていた撮影前の食事制限などをあえて行わず、自然体で臨んだと説明した。女性ファンからの反応についても、初写真集の頃から意識していた女性にも楽しんでもらえるグラビアという目標につながるものとして、活動の励みになっていると述べている。 [ 52 ]

グラビアに対する考え方については、撮影された自身の姿を通じて、その時々の変化や成長を確認できることに面白さを感じていると説明している。

また、声優とグラビアは異なる仕事であるとしながらも、いずれも身体全体を使った表現であるという共通点を挙げ、グラビアを通じた経験が声優としての表現にもよい影響を与えているとの考えを示している。 [ 53 ]
