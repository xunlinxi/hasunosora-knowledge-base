## 経歴

小学3年生か4年生ぐらいに「歌手になりたい」と思っていた時期はあり、将来の夢として、歌っている女の子の絵と一緒に「歌手」と書いていた [ 2 ] 。当時はホットケーキ屋、建築家、デザイナーなどころころ夢が変わっていったという [ 2 ] 。声優と歌手は別物という認識で職業としての声優も無知だったという [ 2 ] 。

声優を目指すようになったきっかけは、中学校の英語の授業で行われた『 不思議の国のアリス 』の絵に声を当てる朗読劇。アリス役を演じた際にクラスメイトから「アリスの声がかわいい」という感想をもらい、演じるということに興味を持ち声の仕事を意識するようになった [ 1 ] [ 7 ] 。もともと好きだったアニメの見方も変わり、『 DEATH NOTE 』で 宮野真守 の声の存在感に感銘を受けた [ 1 ] 。声優を目指した時も「声の表現をしたい」と思っていたため、「アーティスト（歌手）になりたい」とは思っていなかった [ 2 ] 。

中学生の時点ではアルバイトができずレッスンに通う資金が無かったため学校の勉強に集中し、受験を終えた後に声優の勉強ができる学校を探し始めた [ 7 ] [ 8 ] 。複数の専門学校や養成所の体験授業に参加し、その中で見学した よこざわけい子 の授業は良い緊張感があり基礎からしっかり学べると思い、 よこざわけい子 声優・ナレータースクール に入学することを決めた [ 7 ] 。高校時代は養成所に行くためのアルバイトをしており、パン屋、ファストフード店、試食販売、ボーリング場の受付、声優養成所に入所後はスーパーのレジ打ちと、和食料亭、色々な居酒屋で働いていた [ 9 ] 。高校時代は放課後になるとアルバイト先に走って行ったり、いくつか掛け持ちをしたりとアルバイト三昧だったという [ 9 ] 。

印象深いアルバイトについては「初めて本格的に社会に出た」という意味もあり、高校1年生の時から1年半ほど働いていたファストフード店を挙げている [ 9 ] 。そのアルバイトでもう1つ学んだのが「笑顔」で忙しくなると忘れがちだが、与えられた仕事をこなすだけでなく、そこに1つプラスして」お客さんを喜ばせられたらいいな」と意識して働くことで、自然と笑顔でいられるようになった [ 9 ] 。客によっては笑顔を褒めてもらえた人物もおり、モチベーションになった [ 9 ] 。ファストフード店で笑顔でいることを学んだため、スーパーのレジ打ちでニコニコしていたところ話しかけてくれた客が増えたが、スタッフから「レジが詰まっちゃうから笑わないで」と注意されたこともあり、「臨機応変に働くのは難しいな」と思ったという [ 9 ] 。

和食料亭と居酒屋のアルバイトについては夢を追いかけるためには生活していくことも必要だったため、和食料亭は時給の高かったこともあり、村上にとっては助かり、「お客様の間を割って食べ物を置かない」といった細やかなマナーも学べた [ 9 ] 。ちょうど釣りに興味を持ち始めた頃だったため、料理長が魚を捌くところを見せてもらえたのも楽しかった [ 9 ] 。その後の村上が魚を捌けるようになったのもあの時の光景が自然とイメージトレーニングになっていたかも知れないと語る [ 9 ] 。和食料亭でアルバイトをしていた時に天ぷらを運んでいた時に勢いが良すぎてカゴから飛び出した天ぷらが敷紙ごとお客様の机をと滑ってしまったこともあったという [ 9 ] 。

村上にとってアルバイト先は仕事の場所という感じだった [ 9 ] 。アルバイトをしていた時の村上にとっての青春は少しでも声優という夢に近づきたい思いが強く、休日は発声練習をしたりしていたため、時間もお金も全部「声優になりたいという夢」に捧げていた [ 9 ] 。たくさんのバイトをしているのも、夢が関係しており、声優デビューした時に「色々と経験しておいたほうが役を演じるうえで為になるかもしれない」と考えていたところはあったという [ 9 ] 。

高校時代はガールズバンドの活動をしていた [ 3 ] [ 4 ] 。

『 アイカツスターズ! 』の早乙女あこ役でアニメ作品に初出演 [ 1 ] [ 10 ] 。

初主演は『 ミュークルドリーミー 』の日向ゆめ役 [ 11 ] [ 12 ] [ 13 ] [ 14 ] 。

声優デビュー後に歌うようになってからは「声優はこんなに歌って踊るんだ」と知った [ 2 ] 。やっていくうちに「歌での表現も楽しいな、アーティストとしてのお仕事もいつかしてみたい」と思うようになった [ 2 ] 。その後はアーティスト活動がしたくスタッフにも希望を話していた [ 9 ] 。 2021年 9月7日 （自身の誕生日）、 田中ちえ美 （ 虹ヶ咲学園スクールアイドル同好会 でも共演）との 声優ユニット 「 NACHERRY （ナチェリ）」の結成を発表 [ 15 ] 。NACHERRYを結成することになった時はあるライブの翌日にマネージャーは「ライブが終わってから話してあげよう」と思っていたようだったが、その時の村上は爆睡しており、すごく眠い中で電話をしていた [ 3 ] 。その時の話の内容が少し理解できなかったが、寝起きでユニット結成の報を知った時は「起きたばかりで頭が回ってなかったんですけど、嬉しいです」のような感じで夢なのか現実なのかわからないまま、しばらくふわふわしていた [ 3 ] 。田中とユニットが組めると決まった時は嬉しく、田中とは本音を打ち明けられる相手のため「ユニットの相手が田中だなんて絶対に楽しいじゃん！」と思っており、「やりたかったことを言葉にして発信しておいて良かったな」と語る [ 9 ] 。デビュー日はデジタルシングル「フォーチュンテラー」の配信開始日である2021年10月6日（田中の誕生日） [ 16 ] 。

2023年、第17回 声優アワード にて、「虹ヶ咲学園スクールアイドル同好会」として歌唱賞を受賞 [ 17 ] 。

2025年6月、 声帯炎 による発声不良の治療のため、活動を一時制限することを所属事務所を通じて発表 [ 18 ] 。それに伴い、6月19日に出演を予定していた朗読劇『「ネコたん！弐 ぷらす 〜猫町怪異奇譚〜」仮面遊戯殺猫事件』の財部梨杏役を降板、代役を同事務所の 小澤麗那 が務める [ 19 ] [ 20 ] [ 21 ] 。出演予定の『 ゼンレスゾーンゼロ 』のアリス・タイムフィールド役を降板 [ 22 ] [ 23 ] 、代役を 81プロデュース の 田中美海 が務める。

## 人物

虹ヶ咲学園スクールアイドル同好会でも共演し、同じくNACHERRYのメンバーでもある田中ちえ美によると、虹ヶ咲学園スクールアイドル同好会のキャラクターの自己紹介のセリフを収録していた時に田中と最初に出会い、田中にとっての村上の印象は「村上奈津実」よりも「宮下愛役の村上奈津実」だった [ 2 ] 。田中にとっては村上が演じる宮下愛はギャルで明るい子という設定だったこともあり、村上も笑顔がすごく明るく、性格も明るく元気でどちらかというと陽キャだったと思ったことから「きっとなっちゃんは愛ちゃんみたいに明るくはっちゃけたギャルっぽい子なのかな」と思っていた [ 2 ] [ 3 ] 。それに対しては村上は「初めましての日は、愛らしくいよう」と思っていたからだったと語る [ 2 ] 。田中は村上のことについては「ほかの現場で一緒だった子もいて、その子も含めて引っ張っていこう」と思っていたようだったが、接していくと意外と大人しく、皆の意見を聞いているタイプだったと語る [ 2 ] 。その後の村上の印象については田中によると仲良くなっていくうちに村上は「私さ、実は暗いんだよね……」と言うほど結構繊細のため、田中は「実は私、こう思っていたんだよね」と言うと村上は「私もだよ」と言っていたと語る [ 2 ] [ 3 ] 。

兄がいる [ 24 ] [ 25 ] 。

## 人物 ＞ 趣味・趣向

趣味・特技は 釣り 、 けん玉 [ 26 ] 、 ドラム ほか [ 1 ] [ 27 ] 、 節約 など [ 8 ] 。特に釣りは始めた時に魚が多く釣れたことをきっかけに大きくはまっている [ 1 ] 。

好きな食べ物は 肉 や 白米 [ 1 ] 、 カレーライス [ 8 ] 。料理もよくすると語っている [ 8 ] 。

好きなアニメは『 カードキャプターさくら 』で、幼稚園の頃から繰り返し見ている [ 1 ] 。

好きなアーティストは aiko [ 1 ] [ 8 ] 。幼い頃からaikoが好きで、『 カブトムシ 』の歌詞を全部覚えていたぐらい好きで、カラオケでもaikoのメドレーを歌っていた [ 2 ] [ 3 ] 。父が ポルノグラフィティ を好きで、車の中でずっと聴いていた [ 3 ] 。アニソンも好きで、皆で曲を覚えてカラオケで歌ったりしていた [ 2 ] [ 3 ] 。男の子向けのバトル系アニメの主題歌などが好きである [ 2 ] 。小学校、中学校時代の音楽の成績が良くなく、通信簿では「大体良い」と書かれていた [ 3 ] 。

感銘を受けた本は『 博士の愛した数式 』 [ 1 ] 。

所有資格は 漢字検定 準2級 [ 6 ] 。

犬 を飼っており、名前はモカ [ 1 ] [ 28 ] 。

## 人物 ＞ 声優として

仕事をする上でのモットーおよび座右の銘は「なるようになる」 [ 1 ] [ 8 ] 。

声優としてのターニングポイントになった役に『アイカツスターズ!』の早乙女あこを挙げており、人生で大切な存在と語っている [ 1 ] [ 8 ] 。また、印象に残っている役に初めて声のみで泣く芝居を行った『 クイズRPG 魔法使いと黒猫のウィズ 』のウォーブリンガー＝ミリィを挙げている [ 8 ] [ 29 ] 。

「声が特徴的でヒロイン向きじゃない」と言われることもある。目標はラブコメディで正統派のヒロインを演じること [ 1 ] 。

具体的に尊敬している人物はいないが、周りに流されず思ったことをはっきり言える人物に憧れ尊敬している [ 1 ] 。また、演技方面では憧れの声優に 大谷育江 と 釘宮理恵 を挙げている [ 8 ] 。
