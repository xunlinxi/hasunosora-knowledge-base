飯田 ヒカル （いいだ ひかる、 8月28日 [ 3 ] - ）は、 日本 の 女性 声優 。 福岡県 出身 [ 3 ] 。 ラクーンドッグ 所属 [ 3 ] 。

## 略歴

小学生時代に友人の祖母からの助言をきっかけに声優業を知る。当時は小学校でも自身の声が高いことが有名だったことや、中学校の国語の授業で音読を先生に褒められたことがきっかけに、声優になることを決めた [ 4 ] 。

高校3年生の時に福岡で開催された『声優スタジアム2017』にて準グランプリを受賞 [ 5 ] 。これが実際に声優業を志したきっかけだという。高校時代にやっていた演劇では公演で舞台に立つこともあり、同級生は年に1-2回は外部のオーディションを受けていたが、自身は1回も受けてなかったという [ 4 ] 。

プロ・フィット声優養成所 出身 [ 3 ] 。2019年8月より プロ・フィット 預かり所属となる。

2019年10月より放送されたショートアニメ『 天華百剣 〜めいじ館へようこそ！〜 』の透し正宗役がテレビアニメ初出演となった [ 6 ] 。同作では作品声優ユニットの庖丁三姉妹としても活動していた [ 7 ] 。

2022年3月31日をもってプロ・フィットがプロダクション業務を閉鎖したことに伴い [ 8 ] [ 9 ] 、同年4月1日付で ラクーンドッグ へ移籍 [ 10 ] [ 11 ] 。

2024年10月より放送されたテレビアニメ『 君は冥土様。 』の横谷李恋役で初めてアニメのメインキャラクターを演じた [ 1 ] 。

2026年4月1日、ラクーンドッグ預かり [ 12 ] から正所属となる [ 13 ] [ 14 ] 。
