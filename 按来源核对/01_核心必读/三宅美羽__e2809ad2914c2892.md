## 正文

表内区分＝プロフィール；性別＝女性；出身地＝日本 ・ 東京都 [ 1 ]；生年月日＝2001年 12月14日 （24歳）；血液型＝AB型；身長＝151 cm [ 2 ]；職業＝声優；事務所＝アットプロダクション [ 2 ]；公式サイト＝三宅 美羽｜アットプロダクション。

三宅 美羽 （みやけ みう、 2001年 12月14日 [ 2 ] - ）は、 日本 の 女性 声優 。 京都 生まれ、 東京都 出身 [ 1 ] 。 アットプロダクション 所属 [ 2 ] 。 メディアミックス 作品『 ラブライブ！シリーズ 』の 蓮ノ空女学院スクールアイドルクラブ および AiScReam のメンバー。

## 略歴

小学生から中学生にかけて『 かんなぎ 』、『 あの日見た花の名前を僕達はまだ知らない。 』、『 Angel Beats! 』ぐらいの時期の深夜アニメが好きだった [ 3 ] 。そこで職業としての声優があることを知り、「将来お仕事をするなら大好きなアニメの世界で、しかも声優さんだったらアニメの世界に入れている感覚にもなれるから、叶うことなら声優さんになりたいなー」とその気持ちが、年齢を重ねるにつれて強固になっていった [ 3 ] 。深夜アニメに熱中する前は家族で『 ひぐらしのなく頃に 』を観ていたりもしていたため、ちょっと際どい作品が好きだったと語る [ 3 ] 。

芸術系の大学に通い、映画学科の演技コースで学んでいたが、そのOBがオーディオドラマのキャスティングに携わっており、演技コースの学生にオーディションの話を持ちかけていた [ 3 ] 。そのオーディションを受けて選んでもらい、オーディオドラマの吹き替えに参加して声優としての活動を始める [ 3 ] 。大学関係の縁から声優としてデビューすることになったが、その時はすでに事務所に所属していた [ 3 ] 。

テアトルアカデミー 所属を経て [ 4 ] 、2024年7月1日にアットプロダクションに所属 [ 5 ] 。

2025年4月より『 蓮ノ空女学院スクールアイドルクラブ 』の105期生、セラス・柳田・リリエンフェルト役として正式加入。

## 人物

趣味として 映画 鑑賞、 読書 を挙げている [ 1 ] 。特技は「耳の穴に耳を入れること」で、自身のSNSのプロフィール欄にも記載しているほか、自身がゲスト出演した番組においてその特技を披露している [ 1 ] 。

尊敬している声優に 宮本侑芽 を挙げている [ 6 ] 。

同じ事務所所属で、 AiScReam [ メンバー 1 ] のメンバーである 遠藤璃菜 とは、中学生からの付き合いで、遠藤が幼馴染と形容するほど長い交わりがある [ 7 ] [ 注釈 1 ] 。三宅は遠藤を「長い付き合いだけど、尊敬の気持ちが大きい」と評している [ 7 ] 。

同じく蓮ノ空スクールアイドルクラブのメンバーである 楡井希実 とは同じ高校の同窓生だった [ 9 ] 。
